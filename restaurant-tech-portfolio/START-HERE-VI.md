# Bắt đầu từ đây
## Buổi 1: 60–90 phút
1. Đọc README.md và docs/01-project-brief.md. Giải thích mục tiêu bằng lời của bạn.
2. Mở data/requirements.csv bằng Excel hoặc Google Sheets; đọc 8 yêu cầu mẫu.
3. Chọn R01 và R02; tự viết lại tiêu chí chấp nhận và giải thích tại sao cần chúng.
4. Mở data/menu.csv. Đổi hoặc thêm 3 món theo hiểu biết thực tế của bạn; cập nhật test liên quan nếu cần.
5. Ghi một quyết định thật vào docs/05-learning-log.md.

## Tạo repository GitHub
1. Đăng nhập GitHub; chọn New repository.
2. Tên: restaurant-tech-portfolio. Description: POS implementation simulation, restaurant workflows, testing, and staff training.
3. Chọn Private trong khi rà soát thông tin; tạo repository. Có thể chọn Public khi sẵn sàng để nhà tuyển dụng xem.
4. Giải nén ZIP. Upload NỘI DUNG bên trong thư mục restaurant-tech-portfolio để README.md ở gốc repository. Không upload nguyên ZIP.
5. Dùng Upload files trên trang repository; giữ nguyên docs/, data/, career/ và các file gốc. Commit message: Add POS implementation simulation starter.
6. Mở README, thử tất cả link. Nếu folder chưa được giữ nguyên, dùng Add file > Create new file với đường dẫn như docs/01-project-brief.md và dán nội dung tương ứng.
7. Sau mỗi thay đổi có ý nghĩa, tạo commit mô tả đúng việc đã làm.

## Kế hoạch tiếp theo
- Tuần 1: rà soát brief, 8 requirements, ghi POS từng dùng; CV nháp.
- Tuần 2: mở rộng lên 25 món và 15 requirements; giải thích modifier và routing.
- Tuần 3: sơ đồ thiết bị và 8 bài tập support; học network cơ bản.
- Tuần 4: mở rộng 20 test cases; nối requirement với test; ghi rõ chưa chạy nếu không có hệ thống.
- Tuần 5: hướng dẫn nhân viên và video tiếng Anh 3–5 phút.
- Tuần 6: rà soát portfolio, CV, demo và link công khai.

Không cần website riêng để bắt đầu. README là trang giới thiệu đầu tiên. Khi công khai, chỉ ghi những gì bạn đã làm và giải thích được.
